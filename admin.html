Refresh market history

Update the saved daily price history used by your Fintools. Your selected refresh runs through GitHub Actions.

01Select tools to refresh

Choose one or more. Selecting “All tools” includes all four tools. The crash simulator refresh includes DBS, OCBC and UOB; the AI-company tool refresh includes Microsoft, Meta and Google.

02Connect and start refresh

Limit the token to this repository with Actions: read and write and Contents: read and write. The token stays in this page’s memory and is cleared when you close or reload the page.

Select at least one tool and enter the token.

03Open a tool
